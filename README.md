# planckwalkers
Guild Website

Built with Vite, React, TypeScript, Tailwind CSS, daisyUI and Lucide icons.

## Develop

```sh
npm install
npm run dev
```

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages
(`.github/workflows/deploy.yml`). In the repo's Settings → Pages, set
Source to "GitHub Actions" once.

## Layout

One page: a hero at the top, then the leveling timeline section (`#timeline`).
