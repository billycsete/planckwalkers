# Forever Together Plan

## How the Plan Works

WoW is more fun when we get to play together! This plan aims to give the team a guideline for a relaxed leveling plan that keeps us all around the same level with key check-in points where we could group up and run dungeons together as we level.

## Keys to Success

- **Everyone roll a character on an Alliance race on a PvE server.** PvP is a sweat fest for gankers, and we must be in the same faction to group up.
- **Everyone pick one character to go at this relaxed pace!** If you find you're enjoying the game and want to play more, create another character to go fast on, level up professions, or become a day trader at the AH making stacks of gold.
- **The level checkpoints are not strict.** Just a general target, the plan does not break down if people are + or - 2 levels.
- **The plan is adjustable.** We can keep a pulse on if the leveling targets are too fast or slow and adjust the timeline accordingly.

## Alliance Faction Notes

- **Skipped: Ragefire Chasm.** It's inside Orgrimmar, so it's left off the plan. Ruins of Lordaeron is the Horde's dungeon, but Alliance players can sneak in, so it stays.
- **Skyborne** is a new race that can be Alliance. It starts on Zephras Isle (levels 1–12) instead of the old starting zones, so a Skyborne player will meet the group a bit later.
